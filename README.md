# AWS Professor Scheduler

A team project to simplify faculty course assignments. Professors submit their teaching preferences and availability, and a department scheduler reviews recommended matches and approves assignments to course sections.

## Planned features

- Submit preferred courses, teaching days, and time windows.
- Match professors to sections based on qualifications, availability, workload limits, and preferences.
- Review recommendations, approve assignments, and prevent scheduling conflicts.
- View teaching schedules and export approved assignments.

## Technology

The frontend will use HTML, CSS, and JavaScript, with TypeScript for backend logic and infrastructure. The AWS stack includes Amplify Hosting, CloudFront, Route 53, API Gateway, Lambda, and RDS for PostgreSQL. Cognito will provide demo authentication.

## Project status

The project is in the planning and prototyping phase. Our 6–7 person team will first build an interactive HTML demo, then develop an AWS proof of concept over 12 weeks.

The initial version will use synthetic data and fixed course section times. Integration with the University of Kentucky's systems is a future phase, subject to university coordination and access.
